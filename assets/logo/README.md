# CartãoView — Logomarca

Identidade visual do painel de carteiras de cartões. Estilo **fintech vibrante**.

## Conceito
Um cartão estilizado com um mini gráfico de barras ascendente — a fusão de
**Cartão** (o produto) + **View** (a visualização/dashboard dos dados).

## Arquivos
| Arquivo | Uso |
|---|---|
| `cartaoview-horizontal.svg` | Assinatura principal (fundo claro) |
| `cartaoview-horizontal-dark.svg` | Assinatura para fundo escuro |
| `cartaoview-icon.svg` | Símbolo/ícone de app |
| `cartaoview-favicon.svg` | Favicon / uso em tamanho pequeno (64px) |
| `preview.png` | Prancha de apresentação de todas as variações |

Todos os arquivos são **SVG vetorial** — escalam sem perda de qualidade.

## Paleta
| Cor | Hex |
|---|---|
| Roxo | `#A855F7` |
| Índigo | `#6366F1` |
| Ciano | `#22D3EE` |
| Texto escuro | `#0F172A` |
| Texto secundário | `#64748B` |

Gradiente da marca: `#A855F7 → #6366F1 → #22D3EE` (135°).

## Tipografia
Wordmark em sans-serif bold (`Segoe UI` / `Helvetica Neue` / Arial como
fallback). Para congelar o traçado independentemente da fonte instalada,
converta o texto em contornos (paths) no editor vetorial antes de exportar.
